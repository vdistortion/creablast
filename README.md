# <img src="projects/web/public/favicon.svg" width="32" alt="" /> Creablast

Portfolio website for Enesha, a creative copywriter.

**[creablast.ru](https://creablast.ru)**

**Stack:** Angular · TypeScript · SCSS · CSS Grid · Static Site Generation · GitHub Pages

## Development

Node.js version: [`.nvmrc`](.nvmrc).

```sh
npm ci
npm start
```

`npm run build` generates the static site in `dist/web/browser`, including sitemap,
robots.txt and a 404 page. Deploy manually via GitHub Actions.
